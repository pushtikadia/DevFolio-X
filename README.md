## 📖 About
DevFolio-X is a modern, responsive portfolio template designed for developers to showcase their projects, skills, and professional experience with style. It emphasizes performance and aesthetics through a clean glassmorphism UI and fluid user interactions.

---

## ✨ Core Features

*   **🎨 Glassmorphism UI:** A sleek, premium look that brings depth and modern design standards to your portfolio.
*   **🌓 Dark/Light Mode:** Seamless theme toggling for the best user experience regardless of time or setting.
*   **📱 Fully Responsive:** Adaptive layout that looks perfect on mobile, tablet, and desktop screens.
*   **⚡ High Performance:** Built with pure HTML, CSS, and Vanilla JavaScript—no bulky frameworks, ensuring instant load times.
*   **🔗 Interactive Showcase:** Clean sections for projects, technical skills, and social links to make your work stand out.
